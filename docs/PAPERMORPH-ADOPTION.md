# Papermorph / PaperMorphism — adoption decision

## Decision

**Adapt selectively; do not install as the core frontend or as a production dependency.**

The closest identified project is https://github.com/DozenTwelve/Papermorph, an AI authoring skill for creating animated, narrated, interactive web books from source material. It is not a general-purpose CSS design system or React component library. The exact intended resource named PaperMorphism remains unconfirmed.

The repository states an MIT licence. Before running any current version, verify the licence file, release/version, installation instructions, and all scripts against the upstream repository at that time. Do not rely on this note as a substitute for reviewing the current upstream state.

## What River Ways will implement now

- A local, lightweight, editorial-style Demand Engineering field guide at /field-guide/.
- A River Ways-owned design constitution in docs/DESIGN-CONSTITUTION.md.
- Cloudflare Pages headers and static-site fallback configuration.
- No runtime dependency on Papermorph, no model key in the site, no upload of client documents, and no claims that the guide is generated by an AI tool.

The guide is a manually authored proof of concept inspired by the useful interaction pattern. It is not claimed to be output from Papermorph.

## If we later trial the upstream skill

1. Pin a specific commit or release; review the licence and complete source tree.
2. Read all skill instructions and scripts before installation or execution.
3. Run in a development environment with least privilege and no production secrets.
4. Use public, approved source material only; review AI-provider data terms before submitting any non-public content.
5. Treat generated HTML, JavaScript, links, media, and narration as untrusted.
6. Review for unsafe HTML injection, external network calls, trackers, secrets, accessibility defects, and unsupported claims.
7. Run dependency, build, accessibility, link, and browser checks.
8. Deploy only reviewed static output through the Cloudflare pipeline.
9. Measure performance and content usefulness before expanding the experiment.

## Cost model

There is no assumed subscription or package cost in the website runtime because no Papermorph dependency is installed. Any future trial may incur AI-provider usage, human review, media preparation, and maintenance costs. Obtain current pricing from the relevant provider before a trial; do not assume the total cost is zero because a repository is MIT-licensed.

## Security boundary

The public website must not execute the authoring skill, expose model credentials, or accept arbitrary uploaded documents as an authoring job. Any future document-upload or AI-generation service would require a separate server-side design with authentication, quotas, validation, malware/content controls, logging, and privacy review.
